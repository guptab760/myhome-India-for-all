How MyHome uses live data

The app keeps your personal calculations local. It does not pretend a hard-coded interest rate is current. Live lender/insurance/fund data is opened from the source website when you click. This avoids showing stale rates and lets the provider apply your actual eligibility.

Next stage: if you want rates displayed inside MyHome itself, we can add a small serverless API layer (Cloudflare Worker/AWS Lambda) that fetches approved APIs or source feeds and refreshes the data automatically.
